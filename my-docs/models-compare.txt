Retriever

Il demande :

"Quels documents pourraient être pertinents ?"

Reranker

Il demande :

"Parmi ces documents, lesquels répondent réellement le mieux à cette question ?"


how reranking works :
                     Question
                        +
             Document 1
                        ↓
                     Model
                        ↓
                    Score 1

                     Question
                        +
             Document 2
                        ↓
                     Model
                        ↓
                    Score 2

                     Question
                        +
             Document 3
                        ↓
                     Model
                        ↓
                    Score 3

Ensuite on trie les scores

Supposons :
Document 1 → 0.7165
Document 2 → 0.9635
Document 3 → 0.0255

Avant reranking :
1. Document 1
2. Document 2
3. Document 3

Après :
1. Document 2 → 0.9635
2. Document 1 → 0.7165
3. Document 3 → 0.0255

La phrase à retenir:
BGE-M3 cherche vite, Qdrant récupère les candidats, le reranker les réordonne précisément, puis Mistral utilise les meilleurs documents pour générer la réponse.
